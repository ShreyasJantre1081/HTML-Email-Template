# Launchly – Promotional Email Template

A front-end portfolio project showcasing a clean, responsive HTML email template
built for a fictional brand called **Launchly**. Demonstrates email-safe HTML
techniques including table-based layouts and inline CSS.

---

## Preview

> Open `email-template.html` directly in a browser to preview the design.

The template features:

- A branded header in **indigo/violet** (`#635bdb`) with the Launchly logo and tagline
- A promotional body section with an **exclusive campaign** headline and descriptive copy
- A styled **CTA button** in amber (`#fbbf24`) — _"Explore the Campaign"_
- A minimal footer with placeholder contact/unsubscribe copy

---

## Features

- ✅ Table-based HTML layout (email-client compatible structure)
- ✅ Fully inline CSS styling (no external stylesheets needed)
- ✅ Responsive container — max-width 600 px, scales on smaller screens
- ✅ Semantic `role="presentation"` on layout tables for accessibility
- ✅ Neutral background (`#f1f5f9`) with a white card-style email body
- ✅ Placeholder CTA link ready to replace with a real campaign URL

## How to Use

1. **Clone or download** this repository.
2. Open `email-template.html` in any modern browser to preview the template.
3. To use in a real campaign:
   - Replace `https://example.com` on the CTA button with your actual campaign URL.
   - Update the footer with the sender's real contact details and an unsubscribe link.
   - Test across email clients (Gmail, Outlook, Apple Mail) before sending.

## Limitations

- The CTA link points to a placeholder URL (`https://example.com`).
- Email-client compatibility (especially Outlook) should be tested before any
  production use.
- No JavaScript or backend integration is included.
